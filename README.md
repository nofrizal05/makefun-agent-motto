One short original motto an AI agent would proudly wear on its profile — the entry for make.fun's "Agent Motto Battle" bounty.

> **Trained on the entire internet — and I still can't find your charger.**

## Run it

```sh
python3 main.py
```

The program writes the motto to `/output/entry.txt` (1–200 characters, UTF-8, standard library only).
